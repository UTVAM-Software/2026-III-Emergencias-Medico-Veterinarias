# Guía de Instalación y Configuración - Hospital Veterinaria (Emergencias Médico Veterinarias)

Sistema web de gestión veterinaria desarrollado con **HTML5, CSS3, JavaScript (ES Modules)** y una base de datos relacional alojada en **Supabase**.

---

## Prerrequisitos
* Un navegador web moderno (Google Chrome, Firefox, Edge, Brave).
* Un servidor de desarrollo local (como la extensión **Live Server** de Visual Studio Code) o un entorno local como **WampServer**.
* Conexión a internet para la carga de componentes dinámicos y la comunicación con la base de datos en la nube.

---

## Ejecución de la Aplicación
* **Opción A (Visual Studio Code / Live Server):** Abre la carpeta del proyecto en VS Code, da clic derecho sobre `index.html` y selecciona **"Open with Live Server"**.
* **Opción B (Servidor Local WampServer):** Copia la carpeta del proyecto dentro del directorio `www` de WampServer y accede mediante tu navegador local.
